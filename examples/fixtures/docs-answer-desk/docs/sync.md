# Sync and offline mode

Every device keeps a local copy of your calendars and syncs when it can.

## Offline mode

Without a connection you can still read, add and edit events. Changes wait in a local queue and sync as soon as the device is back online.

## Sync conflicts

When two devices edit the same event offline, the edit saved last wins and the other version is kept in the event history, where you can restore it.

## Supported devices

Desktop apps run on the two most recent major versions of each desktop system. Mobile apps need a system released in the last four years.
