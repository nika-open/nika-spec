# Getting started with Tidewren

Tidewren is a shared team calendar. This page takes you from install to your first calendar.

## Install the app

Download the desktop app from the downloads page and open the installer. The mobile app is in your device's app store under the same name.

## Sign in

Sign in with your work email. Tidewren sends a six-digit code to that address; the code expires after ten minutes.

## Create your first calendar

Choose New calendar, give it a name and a colour, then add events with the plus button. A calendar is private until you share it.
